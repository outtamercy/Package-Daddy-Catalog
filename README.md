# Package Daddy Catalog

This is the public, community-maintained catalog that Package Daddy reads for
MO2 plugins, tools, and themes. It is a directory, not a random-download
machine: `listed` does not mean reviewed, and reviewed does not mean
installable. Don't get those twisted.

## How changes get in

This is deliberately **not** a PR queue. A person fills out Package Daddy's
catalog form, Daddy checks the shape, links, dates, duplicate record, and
known conflicts, and the catalog publisher writes the accepted change directly
to this repository. Every direct change is attributed to the GitHub account
that submitted it and leaves a normal Git commit behind.

The form is the bouncer. It accepts structured project facts and useful,
evidence-backed compatibility notes; it is not a public text wall or a way to
smuggle random downloads into somebody else's MO2.

The catalog itself and its field rules live in [catalog/](catalog/). The
publisher deployment lives in [publisher/](publisher/).
